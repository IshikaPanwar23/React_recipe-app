🍲 React Recipe App

A modern React-based web application that allows users to search, explore, and view detailed recipes with ingredients and cooking instructions.

🚀 Features
🔍 Search recipes by name or ingredient
📋 View detailed recipe information
🥗 Display ingredients and instructions clearly
⚡ Fast and responsive UI
📱 Mobile-friendly design
🛠️ Tech Stack
Frontend: React.js
Styling: Tailwind CSS
API: TheMealDB API
State Management: React Hooks (useState, useEffect)
